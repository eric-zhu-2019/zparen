Lisp reads and writes through **streams**. A stream can be the REPL, a file,
or a string in memory. This lesson uses strings, so nothing touches your
disk.

### Format

`format` writes text by following a control string. Its first argument says
where: `t` writes to the REPL, and `nil` returns a new string. Each `~`
starts a **directive**:

```lisp
(list (format nil "~a and ~s" "text" "text")
      (format nil "~d items" 42)
      (format nil "line one~%line two"))
```

`~a` prints a value for people, so a string has no quotes. `~s` prints it so
that Lisp can read it back, with the quotes. `~d` prints an integer, and `~%`
starts a new line.

Directives take numbers before the letter. `~5d` pads a number to 5 columns,
and `~5,'0d` pads it with zeros:

```lisp
(list (format nil "[~5d]" 42) (format nil "[~5,'0d]" 42) (format nil "[~10a]" "left"))
```

### Lists and choices in format

`~{` and `~}` repeat the directives between them for each element of a list.
`~^` stops early on the last element, which is the place for separators:

```lisp
(format nil "~{~a~^, ~}" '(red green blue))
```

`~:[no~;yes~]` picks the first text when its argument is false, and the second
when it is true:

```lisp
(list (format nil "~:[off~;on~]" nil) (format nil "~:[off~;on~]" t))
```

### Strings as streams

`with-output-to-string` gives you a stream that collects what you write to
it, and returns the result as a string:

```lisp
(with-output-to-string (out)
  (princ "two" out)
  (princ " words" out))
```

`with-input-from-string` makes a stream that reads from a string. `read-line`
reads one line. With `nil` as its second argument and a value as its third,
it returns that value at the end instead of signalling an error:

```lisp
(with-input-from-string (in (format nil "first~%second"))
  (list (read-line in nil :eof) (read-line in nil :eof) (read-line in nil :eof)))
```

### Reading Lisp data

`read` reads one Lisp object from a stream. `read-from-string` does the same
from a string:

```lisp
(read-from-string "(1 2 (three))")
```

Never read text from a stranger this way unless `*read-eval*` is `nil`,
because the syntax `#.` asks the reader to run code.

`princ-to-string` and `prin1-to-string` turn any value into a string, like
`~a` and `~s`.

## Exercise: Dollars and cents

Define `(money-string cents)`. It returns the amount as dollars, with a
dollar sign and exactly two digits after the point. `(money-string 1205)`
returns `"$12.05"`.

```stub
(defun money-string (cents)
  (not-written-yet 'money-string))
```

```hint
`(floor cents 100)` returns two values: the dollars and the cents left over.
Catch both with `multiple-value-bind`, and print the cents with `~2,'0d`.
```

```solution
(defun money-string (cents)
  (multiple-value-bind (dollars rest) (floor cents 100)
    (format nil "$~d.~2,'0d" dollars rest)))
```

```check
(is (equal "$12.05" (money-string 1205)))
(is (equal "$0.07" (money-string 7)))
(is (equal "$0.00" (money-string 0)))
(is (equal "$1000.00" (money-string 100000)))
```

## Exercise: A list in a sentence

Define `(list-sentence items)`. It returns the items of the list as one
string, separated by a comma and a space. `(list-sentence '("a" "b" "c"))`
returns `"a, b, c"`. An empty list gives an empty string.

```stub
(defun list-sentence (items)
  (not-written-yet 'list-sentence))
```

```hint
One `format` call does it: repeat `~a` over the list with `~{` and `~}`, and
put `~^` before the separator.
```

```solution
(defun list-sentence (items)
  (format nil "~{~a~^, ~}" items))
```

```check
(is (equal "a, b, c" (list-sentence '("a" "b" "c"))))
(is (equal "x" (list-sentence '("x"))))
(is (equal "" (list-sentence '())))
(is (equal "1, 2" (list-sentence '(1 2))))
```

## Exercise: Add up what you read

Define `(sum-of-read string)`. It reads every Lisp object in the string and
returns the sum of them. Assume every object is a number. An empty string
gives 0.

```stub
(defun sum-of-read (string)
  (not-written-yet 'sum-of-read))
```

```hint
Use `with-input-from-string` to get a stream, then call `read` on it in a
loop. Give `read` the arguments `nil` and a marker such as `:end`, and stop
when it returns the marker.
```

```solution
(defun sum-of-read (string)
  (let ((*read-eval* nil))
    (with-input-from-string (in string)
      (loop for x = (read in nil :end)
            until (eq x :end)
            sum x))))
```

```check
(is (equal 6 (sum-of-read "1 2 3")))
(is (equal 0 (sum-of-read "")))
(is (equal 6 (sum-of-read "10 -4")))
(is (equal 5/2 (sum-of-read "1/2 2")))
```
